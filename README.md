# 70cm_driver
Details of a 70cm driver kit inspired by the original G4BAO 23cm driver project
The decision has been made to not sell any further kits so the designs are now made available here under the terms of an MIT licence. It includes a copy of the original article, Eagle board and schematic files, plus Gerber files for the PCB, which must be made from FR4 0.7mm substrate.
Contains Schematics and PCB layout as image files plus Eagle 7 board and schematic files
Contains Gerber files for the latest v1.1 PCB
Contains images from the tests done by BATC and written up in their house magazine
